# Hob v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A private web assistant ("Hob") on Cloudflare that streams answers, remembers facts about its owner and reads web pages, with Pi Durable running the agent loop inside one Durable Object per user.

**Architecture:** A stateless edge Worker authenticates (Cloudflare Access JWT) and routes `/chat` WebSockets to a `PiAgent` Durable Object whose name the server derives (`u:<userId>`). `PiAgent extends Agent` and hosts `PiHarness`; everything Pi-specific sits behind `src/harness/pi.ts`. Tools are harness-neutral `ToolSpec`s compiled through one policy wrapper. The SPA folds Pi's raw `AgentEvent`s (wire tag `pi-events/1`) with a reducer adapted from Cloudflare's example.

**Tech Stack:** TypeScript, Cloudflare Workers + Durable Objects (SQLite) + AI Gateway, `agents@0.26.0`, `@earendil-works/pi-durable@1.0.4`, `@earendil-works/pi-ai@1.0.4`, Vite 8 + `@cloudflare/vite-plugin`, React 19, Tailwind 4, Vitest 4 + `@cloudflare/vitest-pool-workers`.

**Spec:** `docs/blueprint.md` (section 3 "v0", sections 4–8 for shapes). Verified API facts that override the spec are listed under Global Constraints.

## Global Constraints

- Exact pins: `agents@0.26.0`, `@earendil-works/pi-durable@1.0.4`, `@earendil-works/pi-ai@1.0.4`; npm `overrides` pin `@earendil-works/chord` and `@earendil-works/pi-ai` to `1.0.4`. Commit `package-lock.json`.
- `compatibility_date: "2026-10-06"`, `compatibility_flags: ["nodejs_compat"]`, `"ai": { "binding": "AI", "remote": true }`, DO binding `PiAgent` → class `PiAgent`, `migrations: [{ tag: "v1", new_sqlite_classes: ["PiAgent"] }]` (legacy flow, never `exports`).
- Only `src/harness/pi.ts` imports `@earendil-works/*`, `agents/harness/*`, `agents/models/*` inside `src/`. `web/` may import Pi *types* for the `pi-events/1` reducer.
- Model ids are pi-ai gateway specifiers with hyphens: default `MODEL_ID = "anthropic/claude-opus-5-5"` (the blueprint's `anthropic/claude-opus-4.8` does not resolve). Gateway id var `AI_GATEWAY_ID = "hob"`, metadata `{ app: "hob" }`.
- Pi settings: `retry { enabled: true, maxRetries: 5, baseDelayMs: 1000 }`, `stream { timeoutMs: 300000 }`, `progress { partialIntervalMs: 250, outputIntervalMs: 250 }`, `thinkingLevel: "low"`, compaction left at Pi's default (enabled).
- One conversation: Pi root session `"1"`. Durable Object name is `u:<OWNER_USER_ID>`, built only by `agentName()`.
- Edge strips every request header starting with `x-agents-`, `x-cf-agents-`, `x-partykit-` (covers `x-agents-lifecycle-props`, `x-partykit-props`, and the SDK's `x-cf-agents-subagent-url`). It forwards only the exact path `/chat` (the SDK routes `/sub/<class>/<name>` paths to facets).
- Dev auth bypass only when `url.hostname` is `localhost`/`127.0.0.1` **and** `env.DEV_AUTH === "1"`; `DEV_AUTH` lives only in `.dev.vars`.
- `static options = { sendIdentityOnConnect: false }`; `shouldSendProtocolMessages() → false`; `shouldConnectionBeReadonly() → true`; no `@callable` methods.
- No tools with outside effects; no `ctx.waitUntil`, Pi timers or background tasks.
- `read_page`: http(s) only, own 20 s timeout plus `abortSignal`, body read capped at 2 MB, text capped at 50,000 chars / 2,000 lines, output wrapped `<untrusted source="URL">…</untrusted>`.

## Review Focus

- Reconnect mid-run (phone sleeps, deploy restarts the object): the client replaces its state from the new snapshot with no duplicated messages, and shows "Resuming…" until the run moves.
- Hostile or odd pages: huge bodies, binary types, `</untrusted>` inside the page, redirects, servers that never answer; Stop must still return promptly.
- Gateway failures (bad `MODEL_ID`, spend limit hit, provider error): the owner sees the reason in the UI rather than a spinner that never ends.
- Memory abuse: very long text, odd keys, hundreds of entries, memories written after reading a page (poisoning) are visibly flagged.
- Forged requests: no JWT, wrong audience/issuer/email, injected `x-agents-lifecycle-props`, `/chat/sub/...` paths.
